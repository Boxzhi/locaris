# LUXE Location · 位置中心

Home Assistant 独立位置中心。当前版本 v0.1.0-preview（第一阶段界面重构）。

- 保留原集成目录 `custom_components/luxe_location_probe`、配置项和 SQLite `/config/luxe_location/location.db`，无需重新安装或迁移。
- 四个页面：实时位置、历史轨迹、设备管理、设置。实时与历史地图数据接口尚未接入，不展示模拟定位。
- GPS 有效坐标自动发现、持久化排除、历史开关、30天保留、被动 Recorder 补查均保留。首次开启历史记录自动导入可用历史，暂停后重新开启从当前时间开始。仅对已有位置共享许可的设备开启记录。
- 移除测试地图标记、轨迹、测试按钮、调试日志及模拟地标逆地理编码接口。
- 仅管理员访问；高德安全代理尚未接入。

更新：HACS 更新仓库信息并下载最新提交，重启 HA 后刷新页面。实机回归待验证。
