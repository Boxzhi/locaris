# Locaris · 位置中心

![Locaris](assets/logo.svg)

Home Assistant 独立位置中心。仅管理员访问，被动读取已有 GPS 定位。支持实时位置、历史轨迹、设备管理、运行策略。历史数据保留 30 天，地图及地址解析使用高德服务。

当前版本：v0.2.11-preview，正式版前验收版本。

## 安装

1. 在 HACS 的自定义仓库中添加 `https://github.com/Boxzhi/locaris`，类型选择集成（Integration）。
2. 下载 Locaris 并重启 Home Assistant。
3. 在设置 → 设备与服务 → 添加集成，搜索 Locaris，填写高德 Web JS API Key、JS API 安全密钥及 Web 服务 Key。

本版本是独立安装，不导入其他集成的配置或数据库。数据仅保存在 `/config/locaris/location.db`。首次开启设备历史记录时仍可按原有规则从 HA Recorder 补查现存定位。请仅为有位置共享许可的设备开启历史记录。

## 使用

- 侧边栏「位置中心」包含实时位置、历史轨迹、设备管理、设置。
- 标准、卫星和深色地图可在地图工具栏切换。
- 切换设备及历史定位时，按地图实际尺寸与标记安全边距计算过渡视野；远距离仅适配当前与目标位置（未选中时适配全部），近距离轻微缩放，支持手动操作中断动画。
- 实时位置展示所有已管理且定位可用的设备，不依赖历史记录开关；实时地图和地址解析使用高德服务。列表时间为最近可确认的经纬度或 GPS 精度变化时间，不是 HA 实体更新时间或 GPS 实际采样时间。开启记录的设备可从已授权历史恢复该时间；未开启的设备仅在内存追踪当前定位变化，重启后未知时显示「定位时间未知」，不为此额外读取 Recorder 或写入位置数据。
- 历史记录默认关闭，需手动开启才采集及补查。未开启的设备仅解析当前位置，地址仅暂存在内存，不写入 Locaris 数据库。关闭历史记录后保留之前的历史，不补查关闭期间的定位。
- 历史轨迹显示真实同步状态；停留页面时自动检查记录版本，今日约 10 秒、历史日期约 60 秒、同步期间约 5 秒检查一次。版本未变化时不读取 SQLite 历史列表；变更时静默更新并保留地图视角和列表交互状态。
- 四项运行策略在设置中调整，历史保留固定 30 天。

## 卸载与本地数据

默认保留本地数据。可在位置中心 → 设置 → 数据管理中开启「删除集成时清除本地数据」，该选项保存在 HA 集成配置中，修改即时生效，无需重启。

- HA 重启、禁用集成、重新加载和 HACS 更新均保留数据。
- 需要永久清理时，先开启该选项，再在 HA 设置 → 设备与服务中删除 Locaris 配置项，最后通过 HACS 卸载集成代码并重启 HA。
- 清理范围仅为 `/config/locaris/`（历史定位、地址缓存、设备管理状态和运行策略）；不删除 HA Recorder、其他集成数据或备份。之后重新安装并启用记录时仍可能从 Recorder 补查历史。
- 如果仅删除 HACS 代码，不能保证 HA 调用清理钩子。清理失败会记录 HA 日志；确认不再需要数据并停止 Locaris 后，可手动清理上述目录。

## 品牌及测试

集成目录内 brand/ 已包含深浅主题 Icon、Logo 及高清 PNG。开发者可使用 `python scripts/build_brand.py` 重建图片（需 CairoSVG）。
运行测试：`python -m unittest discover -s tests -p 'test_*.py'`。

真实 HA/HACS 安装及移动端回归尚待验收，不属于正式稳定版。

历史记录只保留首次真实有效定位及后续经纬度或定位精度变化，不再按天写入基准。升级时仅在当前授权区间内清理可确认的连续重复旧记录，保留真实实时变化、首次记录及授权边界外历史；不修改 HA Recorder。无变化日期仅引用保留期及当前授权范围内的此前记录，不存储、不计数、不证明全天停留。Locaris 不主动请求手机定位；实时页面读取 HA 最新实体状态，并对只读请求设置超时及恢复刷新。

定位相关时间统一使用本地日期：当天仅显示 HH:mm:ss，昨日显示「昨日 HH:mm:ss」，今年更早日期显示 MM-DD HH:mm:ss，跨年显示 YYYY-MM-DD HH:mm:ss。历史时间轴同日记录仅显示时间，参考位置保留原始日期时间；无记录时隐藏零计数及重复说明。
